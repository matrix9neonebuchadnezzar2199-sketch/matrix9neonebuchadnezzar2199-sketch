## 03 稼働中のシステム

| 区分 | システム | 概要 | 技術 |
|:--|:--|:--|:--|
| 難読化解除 | [UNVEIL](https://github.com/matrix9neonebuchadnezzar2199-sketch/UNVEIL) | 難読化の検知・種別特定・解除支援 GUI。隔離前提の解析ワークベンチ。 | Rust · Tauri |
| 創作制御 | [ARCANA](https://github.com/matrix9neonebuchadnezzar2199-sketch/ARCANA) ★ | 自然言語で Unity / Blender を操作するオープンソース。公開面の旗艦。 | TypeScript · MCP · Unity |
| 静的トリアージ | [MalCheck](https://github.com/matrix9neonebuchadnezzar2199-sketch/MalCheck) | 検体の静的トリアージ。実行展開はしない。lab 向けの第一視線。 | Python · PE |
| 境界監視 | [USB-GuardDuty](https://github.com/matrix9neonebuchadnezzar2199-sketch/USB-GuardDuty) | 可搬媒体からの持ち込みを監視するガード。ホスト側の衛生。 | Python · Windows |
| エアギャップ LLM | [Local_LLM_Notepad](https://github.com/matrix9neonebuchadnezzar2199-sketch/Local_LLM_Notepad) | 単一 EXE。ネットも管理者権限も要らない、持ち歩き可能な局所推論。 | Python · local model |
| N次元 | [dimensional-simulator](https://github.com/matrix9neonebuchadnezzar2199-sketch/dimensional-simulator) | 多次元多面体の投影・展開・超平面通過。単一 HTML の航路儀。 | HTML · WebGL |
